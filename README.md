# simaodev

Site pessoal e estúdio de landing pages pra profissionais
e pequenos negócios do Triângulo Mineiro.

**Status:** em construção · v0.1

## Stack
- HTML, CSS e JavaScript puros (sem framework)
- Deploy: Vercel
- Domínio: simaodev.com.br (em breve)

## Estrutura
- `index.html` — página principal
- `styles.css` — design system e componentes
- `script.js` — interações (cursor, terminal, animações)
- `prototipos/` — modelos por nicho (advocacia, imobiliária, psicologia, despachante)
- `assets/` — imagens, ícones, favicon
